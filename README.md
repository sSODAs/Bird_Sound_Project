# Bird Sound Project

Signal Processing Course Project

## Project Goal

Identify bird species from bird-call recordings and compare different signal-processing approaches based on:

- Identification accuracy
- Processing time

## Current Project Structure

- data/raw/ : original audio recordings
- data/processed/ : preprocessed audio
- data/metadata/ : dataset metadata and train/test split
- notebooks/ : experiment notebooks
- src/ : reusable Python code
- outputs/ : generated results and figures
- docs/ : references and project notes
